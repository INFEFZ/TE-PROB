# Lernziele

- [ ] Sie können die prinzipielle Vorgehensweise der Entwicklung eines Windows-Programms mit einfacher Ein-Ausgabe in einem Fenster schildern.
- [ ] Erstellen eines Fensters unter Windows
- [ ] Ausgabe eines Textes auf das Fenster
- [ ] Einlesen eines Wertes aus dem Fenster

- [ ] Sie kennen den Unterschied zwischen einer sequentiellen Datei und einer random Datei und können den Aufbau anhand einer Beispielskizze erklären.
- [ ] Sie können anhand einer einfachen Beispielskizze die Struktur des Typs FILE erklären.
- [ ] Sie kennen die möglichen Attribute von Dateien und können diese in Programmen lesen und schreiben.
- [ ] Sie können die wichtigsten High-Level Funktionen für die Ein- und Ausgaben von Dateien in Programmen anwenden.
- [ ] Sie können Informationen formatiert, zeichenweise, String weise und blockweise in Programmen mit Dateizugriff schreiben und lesen.
