## Lernziele

- [x] Sie kennen die Vorteile der **Modularisierung** von Programmen und können diese in Programmierprojekten anwenden.
- [x] Sie können per Makefile ein C-Projekt mit **mehreren Dateien** erstellen

- [x] Sie  kennen das Prinzip der einfachen **Rekursion** und können das Prinzip an einem Beispiel erklären.
- [x] Kann anhand einer Beispieldeklaration erklären, was man unter einem rekursiven Datentyp versteht.
- [x] Sie kennen die Möglichkeiten der Array- und String Initialisierung und können diese in Programmen anwenden.
- [x] Sie können die wichtigsten String Funktionen für Vergleich, Längenermittlung, Zuweisung und Kopieren von Zeichen in Programmen anwenden.
- [x] Sie kennen die String-Konvertierungsfunktionen (Bsp. `atoi`, `itoa`) und können diese in Programmen anwenden.
- [x] Sie können eigene Datenstrukturen vom Typ „struct“ formulieren und diese in Programmen anwenden.
- [x] Sie kennen das Prinzip von Bitfeldern für die effektive Speichernutzung und können diese in Programmen verwenden.
