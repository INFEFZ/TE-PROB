## Lernziele

- [x] Kann die binäre Suche von Daten in einem sortierten Array anhand eines Beispiels erklären.
- [x] Kennt die wichtigsten Sortieralgorithmen.
- [x] Kann ihre Zeitkomplexität verschiedener Sortieralgorithmen einschätzen und begründen, welcher Algorithmus für welches Szenario geeignet ist.
- [x] Sie kennen den Unterschied zwischen einer sequentiellen Datei und einer random Datei und können den Aufbau anhand einer Beispielskizze erklären.
- [x] Sie können anhand einer einfachen Beispielskizze die Struktur des Typs FILE erklären.
- [x] Sie kennen die möglichen Attribute von Dateien und können diese in Programmen lesen und schreiben.
- [x] Sie können die wichtigsten High-Level Funktionen für die Ein- und Ausgaben von Dateien in Programmen anwenden.
- [x] Sie können Informationen formatiert, zeichenweise, String weise und blockweise in Programmen mit Dateizugriff schreiben und lesen.
