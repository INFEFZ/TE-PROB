## Lernziele

- [x] Sie kennen das Prinzip von Bitfeldern für die effektive Speichernutzung und können diese in Programmen verwenden.
- [x] Sie kennen Sinn und Zweck der Aufzählungstypen (enum) und diesen in Programmen anwenden.

- [x] Kann das Prinzip von FIFO und LIFO Strukturen anhand einer Beispielskizze erklären.
- [x] Kann den Unterschied und demzufolge Vor-/Nachteile zwischen einer einfachen und einer doppelt verketteten Liste anhand eines Beispielskizze aufzeigen.
- [x] Kann dynamische Listen mit einfacher Verkettung in eigenen Programmen anwenden.
- [x] Kann dynamische Listen manipulieren (Bsp. einfügen, löschen, sortieren von Elementen) und die Funktionen in eigenen Programmen anwenden.

- [x] Anforderungen, Vorgaben, Voraussetzungen und Abgabe der Praxisarbeit ist bekannt.
