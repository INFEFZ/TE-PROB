## Lernziele

- [X] Sie kennen den Unterschied von **globalem** und **lokalem** Gültigkeitsbereich von Variablen und können diese in Programmen nutzen.
- [X] Sie können **Funktionen** mit/ohne **Parameter** und mit/ohne **Rückgabewert** für Programme entwickeln
- [X] Sie können die `return`-Anweisung innerhalb von Funktionen sinnvoll anwenden.
