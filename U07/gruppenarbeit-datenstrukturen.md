# Gruppenarbeit Datenstrukturen

## Ziel der Gruppenarbeit

In dieser Gruppenarbeit sollt ihr euch intensiv mit einer grundlegenden Datenstruktur auseinandersetzen. Ziel ist es, dass ihr sowohl das theoretische Verständnis als auch die praktische Anwendung (inklusive Implementierung in C) beherrscht. Eure Ergebnisse präsentiert ihr der Klasse in einer **20–25-minütigen Präsentation im Markdown-Format**.

## Themenwahl

Jede Gruppe bearbeitet eine der folgenden Datenstrukturen:

- **Einfach verkettete Liste**
- **Doppelt verkettete Liste**
- **Stack**
- **Queue**
- **Baumstrukturen**
  - Binärbaum
  - B+ Baum

> **Hinweis: Pro Datenstruktur kann maximal eine Gruppe ausgewählt werden.**

## Gruppengrösse

- Die Gruppen bestehen aus **maximal 3 Mitgliedern**.
- Zweiergruppen sind ebenfalls möglich.

## Aufgabenstellung

Jede Gruppe muss für ihre Datenstruktur folgende Punkte bearbeiten:

- **Erläuterung der Datenstruktur**
  - Allgemeine Definition
  - Aufbau und Funktionsweise
- **Grafische Skizzierung des Aufbaus**
  - Darstellung der Struktur (z. B. Knoten und Zeiger bei Listen, Baumknoten, Warteschlange usw.)
- **Erläuterung der wichtigsten Operationen**
  - Hinzufügen (Insert), Löschen (Delete), Suchen (Search), Traversieren usw.
  - Grafische Veranschaulichung jeder Operation (z. B. was beim Einfügen oder Löschen passiert)
- **Vor- und Nachteile**
  - Welche Stärken hat die Datenstruktur?
  - Welche Schwächen / Limitierungen existieren?
- **Einsatzbereiche**
  - Wo und warum wird die Datenstruktur praktisch eingesetzt?
  - Beispiele aus Programmiersprachen, Algorithmen, Betriebssystemen, Datenbanken etc.
- **Implementierung in C**
  - Kurzer, sauber kommentierter Beispielcode zur grundlegenden Nutzung der Datenstruktur
  - z.B. Insert/Delete/Search bei Listen, Push/Pop bei Stack, Enqueue/Dequeue bei Queue, Insert/Delete bei Baumstrukturen
  - Kein vollständiges Framework notwendig – es reicht eine illustrative Implementierung
- **Präsentation**
  - Dauer: **20–25 Minuten**
  - Format: **Markdown** (z.B. für GitHub oder GitBook geeignet)
  - Inhalte klar strukturiert, mit Code-Beispielen, Grafiken und ggf. Animationen
  - Mitbeteiligung aller Gruppenmitglied zu gleichen Teilen
- **Quiz**
  - Am Ende der Präsentation muss jede Gruppe ein **Quiz mit mindestens 5 Fragen** vorbereiten
  - Fragen sollen Verständnis prüfen (nicht nur Faktenwissen)
  - Quiz kann interaktiv durchgeführt werden (z.B. Kahoot, Mentimeter oder einfache Fragen an die Klasse)
- **Abgabe**
  - Präsentation (Markdown) und alle Codebeispiele werden als **GitHub Link (öffentliches Repository)** zur Verfügung gestellt.
  - Termin: **30.08.2025, 09:00 Uhr** (spätere Abgaben werden nicht berücksichtigt).
  
## Bewertungskriterien

- Inhaltliche Vollständigkeit (Erläuterungen, Grafiken, Beispiele)
- Code-Qualität (korrekt, lesbar, kommentiert)
- Darstellung (Klarheit, Struktur, Visualisierung)
- Präsentationsstil (verständliche Erklärung, Zeitmanagement, Teamarbeit)
- Quiz (Relevanz der Fragen, Aktivierung der Zuhörer)

### Teilprüfung (TP)

Es werden 3 Bewertungsoptionen berücksichtigt, die bei der Benotung der Teiprüfung einfliessen:

- **Ausgezeichnet**: Note Teilprüfung + 0.5
- **Gut**: Note Teilprüfung + 0.25
- **Sonst**: Note Teilprüfung + 0
