# Lernziele

- [ ] Sie können das Prinzip von FIFO und LIFO Strukturen anhand einer Beispielskizze erklären.
- [ ] Sie können den Unterschied und demzufolge Vor-/Nachteile zwischen einer einfachen und einer doppelt verketteten Liste anhand eines Beispielskizze aufzeigen.
- [ ] Sie  können anhand einer Beispieldeklaration erklären, was man unter einem rekursiven Datentyp versteht.
- [ ] Sie können dynamische Listen mit einfacher Verkettung in eigenen Programmen anwenden.
- [ ] Sie können dynamische Listen manipulieren (Bsp. einfügen, löschen, sortieren von Elementen) und die Funktionen in eigenen Programmen anwenden.
